# Rook Foundations logo

- `rook-foundations-logo.svg` / `.png` — the logo: white R on the gold rounded tile (#E8A020). Use this by default.
- `rook-foundations-mark.svg` — the R on its own, in gold, for places where the tile would be too heavy.

The website draws the R from `src/components/ui/RookMark.jsx`; favicons and app icons in `public/` are generated from the same shapes.
